## Как устроены креды (v2)

`POST /api/v2/access_token` требует три значения:

| Поле | Где взять |
|------|-----------|
| `apiKey` | iiko → приложение «Настройки Cloud API» → Интеграции → ключ |
| `appId` | Портал разработчика api.iiko.ru → приложение |
| `clientSecret` | там же, при создании приложения (показывается один раз) |

Все три — в `.env` (не в git): `IIKO_API_KEY`, `IIKO_APP_ID`, `IIKO_CLIENT_SECRET`.
